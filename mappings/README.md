# Cross-framework mappings

Reviewed mappings between two frameworks' records in a client repository live here, as `mappings/<a>__<b>.yaml`. The engine ships proposed mappings (for example `iso27001__iso42001.yaml`). Copy one here, review each line, and fill `reviewed_by` and `reviewed_on`.

Only reviewed `equivalent` mappings let evidence from one record be cited in the other (`iso42001:EV-001`).

See [`docs/FRAMEWORKS.md`](../docs/FRAMEWORKS.md).
