# Seshat brand

Working logo (concept C1, "Human in the loop"), November 2026. The orbit is the loop; its one opening is held by a
person, so nothing goes round without passing them. The spark at the centre is the AI. Line: *AI does the work.
People decide.*

| File | Use |
|---|---|
| `seshat-logo-dark.svg` / `.png` | Horizontal logo on dark backgrounds |
| `seshat-logo-light.svg` / `.png` | Horizontal logo on light backgrounds |
| `seshat-mark-dark.svg`, `seshat-mark-light.svg` | The mark alone |
| `seshat-icon.svg` / `.png` | App icon (512 px), and the client site's and rooms' icon |
| `seshat-favicon.svg` | 32 px and below |

Colours: emerald `#34D399`, teal `#14B8A6`, the person `#D9F99D`, the spark `#ECFDF5`, on forest `#08110F` /
`#0E201C`. On light backgrounds: `#059669`, `#0D9488`, person `#3F6212`, text `#0B1F1A`.

The wordmark is Sora Bold, outlined into the SVG, so no font is needed to show it. Sora is licensed under the SIL
