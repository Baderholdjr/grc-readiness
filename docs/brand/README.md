# Yata brand

The product was called Seshat until November 2026; it is now Yata (after the Yata no Kagami, the sacred mirror
that shows things as they are).

Logo: concept D1, "Ensō loop", November 2026. One brush circle is the loop; its only gap is held by a person, so
nothing goes round without passing them. The spark inside is the AI. Line: *AI does the work. People decide.*

| File | Use |
|---|---|
| `yata-logo-dark.svg` / `.png` | Horizontal logo on dark backgrounds |
| `yata-logo-light.svg` / `.png` | Horizontal logo on light backgrounds |
| `yata-mark-dark.svg`, `yata-mark-light.svg` | The mark alone |
| `yata-icon.svg` / `.png` | App icon (512 px), and the client site's and rooms' icon |
| `yata-favicon.svg` | 32 px and below |

Colours: emerald `#34D399`, the person `#D9F99D`, the spark `#ECFDF5`, on forest `#08110F` /
`#0E201C`. On light backgrounds: ink `#065F46`, spark `#059669`, person `#3F6212`, text `#0B1F1A`.

The brush texture is an SVG filter (fractal noise displacement), so the edges render the same everywhere. The
wordmark is Kaushan Script, outlined into the SVG, so no font is needed to show it. Kaushan Script is licensed under
the SIL Open Font License 1.1 (`KaushanScript-OFL.txt`). The favicon is a plain, unbrushed version for 32 px and below.

Before using the name commercially, run a trademark search (USPTO) and check domain availability.
