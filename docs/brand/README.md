# Yata brand

The product was called Seshat until November 2026; it is now Yata (after the Yata no Kagami, the sacred mirror
that shows things as they are). The files here are the interim logo: concept C1's mark with a YATA wordmark. A
brush-calligraphy logo is being designed to replace them.

Interim logo (concept C1, "Human in the loop"). The orbit is the loop; its one opening is held by a
person, so nothing goes round without passing them. The spark at the centre is the AI. Line: *AI does the work.
People decide.*

| File | Use |
|---|---|
| `yata-logo-dark.svg` / `.png` | Horizontal logo on dark backgrounds |
| `yata-logo-light.svg` / `.png` | Horizontal logo on light backgrounds |
| `yata-mark-dark.svg`, `yata-mark-light.svg` | The mark alone |
| `yata-icon.svg` / `.png` | App icon (512 px), and the client site's and rooms' icon |
| `yata-favicon.svg` | 32 px and below |

Colours: emerald `#34D399`, teal `#14B8A6`, the person `#D9F99D`, the spark `#ECFDF5`, on forest `#08110F` /
`#0E201C`. On light backgrounds: `#059669`, `#0D9488`, person `#3F6212`, text `#0B1F1A`.

The wordmark is Sora Bold, outlined into the SVG, so no font is needed to show it. Sora is licensed under the SIL
Open Font License 1.1 (`Sora-OFL.txt`).

Before using the name commercially, run a trademark search (USPTO) and check domain availability.
